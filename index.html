Porquê o EndoInsight?

A solução ideal para Faculdades de Medicina e Centros de Treino

Alta Fidelidade Tátil

Silicone biomimético que replica com precisão a densidade de nódulos superficiais e profundos.

Métricas Objetivas

Elimine a subjetividade na avaliação com relatórios detalhados de pressão e localização.

Custo Reduzido

Tecnologia de ponta a uma fração do custo dos manequins de simulação tradicionais.


Visão Geral

O projeto consiste no desenvolvimento de um simulador físico para treino do exame pélvico bimanual, com foco na deteção de endometriose superficial e profunda. O sistema integra um modelo anatómico realista, sensores de pressão e uma interface gráfica que fornece feedback em tempo real.

Demonstração do Simulador em Funcionamento

Objetivos do Projeto

Formação Médica

Proporcionar treino seguro e repetitivo para estudantes de medicina e residentes.

Feedback Tátil

Simular diferentes densidades de nódulos para treino de palpação diferenciada.

Avaliação de Desempenho

Quantificar a precisão e técnica de palpação através de métricas objetivas.

Diagnóstico Precoce

Contribuir para o diagnóstico precoce da endometriose através de melhor formação.

Componentes do Sistema

Modelo Anatómico Realista

  • Material: Silicone biomimético de grau médico
  • Escala: 1:1 reprodução anatómica feminina
  • Nódulos: Multipla densidade (7-30 Shore A)
  • Áreas: Útero, ovários, ligamentos uterossacrais
  • Substituição: Nódulos intercambiáveis

Sistema Eletrónico

  • Sensores: 24 FSR (Force Sensitive Resistors)
  • Microcontrolador: ESP32 com Wi-Fi/Bluetooth
  • Aquisição: Taxa de amostragem de 100Hz
  • Comunicação: USB Serial + BLE
  • Alimentação: USB 5V / Bateria Li-Po

Software de Interface

  • Linguagem: Python 3.8+
  • GUI: PyQt5 para interface moderna
  • Visualização: OpenCV para processamento de imagem
  • Relatórios: Geração automática em PDF
  • Base de dados: SQLite para armazenamento de sessões

Requisitos do Sistema

Hardware

  • Processador: Intel i5 ou equivalente
  • Memória RAM: 8GB mínimo
  • Armazenamento: 500MB livres
  • Porta USB 2.0/3.0

Software

  • Python 3.8 ou superior
  • Bibliotecas: PySerial, PyQt5, NumPy
  • Sistema: Windows 10/11, macOS 10.15+
  • Drivers USB instalados

Instalação

  1. Extrair arquivo ZIP baixado
  2. Instalar Python 3.8+
  3. Executar pip install -r requirements.txt
  4. Conectar simulador via USB
  5. Executar python main.py

Ética e Segurança

O EndoInsight é um projeto desenvolvido exclusivamente para fins académicos, educativos e de investigação.

O sistema apoia o treino técnico do exame pélvico bimanual. Não possui finalidade clínica. Não substitui exames médicos, diagnósticos ou decisões terapêuticas.

Todos os dados utilizados são simulados. Não são recolhidos, armazenados ou processados dados reais de pacientes.

O hardware foi projetado para utilização segura em ambiente académico. Os sensores operam dentro de limites controlados e não envolvem componentes invasivos.

A interface fornece apenas feedback informativo. Os resultados não devem ser interpretados como indicadores clínicos.

Evoluções futuras devem respeitar princípios éticos, normas de segurança e regulamentação aplicável a sistemas de apoio à saúde.
